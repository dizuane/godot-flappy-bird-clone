# godot-flappy-bird-clone 

## Description 
A flappy bird clone created in Godot 4.7.1 stable.

## Goals 
The overall goal is to start learning and using Godot for game development.

### Features  
- Gravity
- Animations
- Scrolling pipes
- Scoring
- Parallax scrolling backgrounds
- Full gameplay loop

### Learning Goals
- Parallax
- Asset handling
- Scenes
- Nodes
- GD Script (beyond barebones basics)
- Inheritance in Godot
- Signals (using Signal Bus pattern)
- Autoloads
- Transitions
- UI and Canvas
- Data persistence to file
- Physics nodes
